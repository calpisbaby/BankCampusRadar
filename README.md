# 银招雷达 · BankCampus Radar

**国内应届生银行秋招/春招信息监测网页应用** —— 面向 2025/2026/2027 届毕业生，全量监测六大国有银行、股份制银行、城商行、农商行、外资行的校园招聘动态，每日更新。

## 快速开始

1. **直接使用**：双击打开 `index.html`（无需服务器，纯静态 SPA，数据内嵌）。
2. **每日更新**：参见 `collector/README.md`，或由 Hermes cron 每日自动巡检（见下文）。
3. **数据说明**：`data/` 下三个 JS 文件即底层数据，采集器每日合并更新。

## 功能对照

| 需求 | 实现 |
|---|---|
| ① 机构分类 | 国有银行 6 家 / 股份制银行 12 家 / 城商行 14 家 / 农商行 4 家 / 外资行 12 家（共 48 家） |
| ② 日更频率 | cron 每日 09:00 巡检；工作台显示数据更新时间 |
| ③ 历史数据 | 2024-09 至今共 184 条岗位记录：2025 届秋招提前批/正式批、2025 届春招、2026 届秋招提前批/正式批、2026 届春招、2027 届秋招提前批；之后每天增量合并 |
| ④-0 监控工作台 | 截止今日开放岗位总数、招聘银行家数、已收藏岗位数、近 7 日新增（含总行岗位数、类型覆盖等副指标） |
| ④-1 筛选区 | 地区（全国→省份→城市，级联下钻、下钻框向右延伸）、银行类型、机构层级（总行/境内分支行/港澳台及海外机构/子公司）、时间（2024/2025/2026，随数据自动新增）、招聘批次（秋招提前批/秋招正式批/春招提前批/春招正式批）+ 银行名称模糊搜索框 |
| ④-2 排序 | 无筛选时展示全量银行岗位，按中国银行业协会《2025 年中国银行业前 100 名单》排名排序（外资行在百强之后，按自定义序列） |
| ④-3 信息展示 | 加粗放大银行名称 + 岗位类型 + 最低学历 + 岗位地点 + 投递截止日期；每条信息带三个可点击插件：招聘官网 / 招聘公告 / 收藏星标；筛选联动（如机构层级=总行时仅显示总行岗位） |
| ④-4 详情页 | 左上角返回；银行 Logo（品牌色徽章）+ 银行名称；小图标信息区（工作地点/岗位名称/招聘时间/招聘批次/开放时间/截止时间/收藏）；下方工作职责、注意事项、招聘链接（官网/公告/公众号）、该银行其他岗位推荐（可跳转本应用对应详情页） |
| ⑤ 数据收集 | `collector/collect.py` 每日抓取 48 家银行招聘官网 + 官方公众号清单人工核验；`commit_pending.py` 增量合并历史库 |

## 目录结构

```
BankCampusRadar/
├── index.html                  # SPA 入口（工作台/列表/详情/收藏）
├── css/style.css               # 设计系统（监控工作台风格）
├── js/app.js                   # 前端逻辑（路由/筛选/收藏/统计）
├── data/
│   ├── meta.js                 # 元数据（更新时间/数据源数）
│   ├── banks.js                # 48 家银行（百强排名/类型/品牌色/官网/公众号）
│   └── positions.js            # 岗位历史库（184 条，2024-09 至今）
├── collector/
│   ├── collect.py              # 每日巡检采集器（纯标准库）
│   ├── commit_pending.py       # 审核后合并入库
│   ├── bank_sources.json       # 48 家银行数据源清单
│   └── README.md               # 采集器说明 + 公众号清单
└── validate.js                 # 数据完整性校验（node validate.js）
```

## 页面说明

- **工作台**：顶部 KPI 监控卡（岗位总数/银行家数/收藏数/近 7 日新增）→ 筛选区（级联地区下钻 + 5 个下拉 + 模糊搜索 + 状态切换）→ 岗位列表（百强排名徽章、银行名、类型、层级、学历、地点、截止倒计时、官网/公告/星标）。
- **详情页**：`#/p/<岗位ID>`，含银行 Logo、图标信息区、职责/注意事项/链接/同银行岗位推荐。
- **收藏夹**：`#/fav`，星标持久化在浏览器 localStorage，跨会话保留。

## 数据校准说明

- 排名参考中银协《2025 年中国银行业前 100 名单》（按一级资本）；外资行不在百强名单内，按自定义序列排在百强之后。
- 岗位信息（批次时间、岗位类型、截止日期等）为基于公开信息的种子数据，**由每日采集器持续校准**；正式使用前建议人工核对一轮。
- 所有招聘信息以各银行官方招聘网站及官方公众号发布为准，本应用仅做监测聚合，不代投递。

## 部署为共享网页应用（第 4 项需求）

应用为**纯静态站点**（HTML/CSS/JS + data/*.js），无需后端即可托管，三种方式任选：

### 方案 A：GitHub Pages（推荐，免费 + 可每日自动更新）
1. 在 GitHub 新建仓库（如 `BankCampusRadar`），把本项目推送上去（`git init && git add . && git commit -m "init" && git remote add origin <仓库地址> && git push -u origin main`）。
2. 仓库 Settings → Pages → Source 选择 **GitHub Actions**（仓库已内置 `.github/workflows/deploy.yml`，推送即自动校验数据并部署，无需手动开关）。
3. 访问地址：`https://<用户名>.github.io/BankCampusRadar/`。
4. **每日数据同步**：本机采集器（cron 每日 09:00）跑完后 `git add data/ && git commit -m "daily update" && git push`，网站即自动重新部署。可将这步写进 cron 提示词（每日巡检摘要后执行）。

### 方案 B：Netlify / Vercel / Cloudflare Pages（拖拽即部署）
- Netlify：https://app.netlify.com/drop —— 把 `index.html`、`css/`、`js/`、`data/` 四个文件/目录直接拖进去即得公网地址；后续数据更新重新拖一次即可。
- Vercel / Cloudflare Pages：同样支持静态站点导入（Build 命令留空，输出目录 `.`）。

### 方案 C：局域网快速共享（无需公网）
```bash
cd C:\Users\darkflorence\BankCampusRadar
python -m http.server 8000 --bind 0.0.0.0
```
同一 Wi-Fi 下的设备访问 `http://<本机IP>:8000/`；仅限本机开机且在同一网络时可用。

### 说明
- 收藏功能（localStorage）按浏览器隔离：每个访问者各自独立收藏。
- 采集器必须在本机或某台常开机器上运行（cron 每日 09:00），数据通过 git 推送到托管端。
- 若需多用户共享收藏/账号体系，需要引入后端（后续可按需扩展）。

## Hermes 每日自动巡检

```bash
# 手工触发一次
hermes cron run <job_id>
```

- 每天 09:00 自动运行 `collector/collect.py --deep`，智能体审核新增公告、补全字段、调用 `commit_pending.py` 入库、运行 `validate.js`，并在聊天中输出当日摘要（新开放岗位、临期岗位提醒等）。
